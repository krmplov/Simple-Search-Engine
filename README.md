# Simple Search Engine

#### _Простой полнотекстово поиск над файлами_

> В данном проекте реализовано две программы: индексатор (подготовка поискового индекса) и поиск (программа, осуществляющая поиск по построенному индексу).
Также реализованы функции ранжирования [BM25](https://en.wikipedia.org/wiki/Okapi_BM25), а в качестве фактора для нее [TF-IDF](https://en.wikipedia.org/wiki/Tf%E2%80%93idf).
***
## Требования к программам
### индексируемая программа
* консольное приложение
    * _структура аргементов_:
    > to specify the directory for indexing, enter "--path" and then enter the name of the directory
    to indicate the names of files or directories that don't need to be taken into account when indexing,enter "--exclude" and then enter all the names of files or directories
* обход всех файлов по определенной директории происходит рекурсивно

### поисковая программа
* консольное приложение, взаимодействие с пользователем через стандартные потоки ввода и вывода
* осуществлен поиск по построенному индексу
* ранжировка найденных документов согласно BM25
* выдача в качестве результата список файлов с номерами строк где встречается данное слово
* поддержка синтаксиса запросов с "AND" и "OR"
* неккоерктный запрос приводит к выводу ошибки
* поиск регистронезависимый
***
## Синтаксис запросов
> синтаксис поддерживает скобки и операции AND и OR (регистр имеет значение). Таким образом в качестве запроса выступают логические выражения. Разделитель - пробел(ы)

### _корректно_
* "for"
* "vector OR list"
* "vector AND list"
* "(for)"
* "(vector OR list)"
* "(vector AND list)"
* "(while OR for) and vector"
* "for AND and"

### _некорректно_
* "for AND"
* "vector list"
* "for AND OR list"
* "vector Or list"
